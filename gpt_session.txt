## 2. Offline Speech-to-Text (STT) — Working

I have a working offline STT system using **Sherpa-ONNX Whisper** with a Hindi/Hinglish-oriented model.

Model directory:

```text
models/hi-hinglish-swift/
├── encoder.int8.onnx
├── decoder.int8.onnx
└── tokens.txt
```

Relevant packages:

* `numpy`
* `soundfile`
* `sherpa-onnx`

The recognizer is initialized with:

```python
recognizer = sherpa_onnx.OfflineRecognizer.from_whisper(
    encoder=str(MODEL_DIR / "encoder.int8.onnx"),
    decoder=str(MODEL_DIR / "decoder.int8.onnx"),
    tokens=str(MODEL_DIR / "tokens.txt"),
    num_threads=2,
    decoding_method="greedy_search",
    language="hi",
    task="transcribe",
)
```

The reusable transcription function is `transcribe_wav(audio_path)`. It reads WAV files using `soundfile`, converts stereo to mono, ignores near-silent audio, and returns the recognized text.

**Important:** WAV files must be 16 kHz. The current STT validation expects `16000` Hz. Previously, the sample-rate constant and error message were inconsistent, causing confusion. Keep recording, WAV validation, and `stream.accept_waveform()` aligned at 16 kHz.

The original `offline_stt.py` used `/home/piuser/savan` as its base directory. It was subsequently adapted to the newer project at `~/sathi-personal-ai-companion/rasp`. Verify that file paths now point to the actual project directory.

## 6. Existing Memory/LLM Application

The project already has these modules:

* `database.py`, exposing `init_db()` and `get_all_transcriptions()`
* `llm.py`, exposing `ask_gemma(question, memories)`
* `ask_memory.py`, which retrieves stored transcriptions and sends questions to Gemma.

The current `ask_memory.py` logic is:

```python
from database import init_db, get_all_transcriptions
from llm import ask_gemma

init_db()

print("Loading memories...")
memories = get_all_transcriptions()
print(f"Found {len(memories)} memories.")

while True:
    question = input("\nYou: ").strip()

    if question.lower() in ["exit", "quit"]:
        break

    if not question:
        continue

    answer = ask_gemma(question, memories)
    print()
    print("Gemma:", answer)
```

We want to add TTS so the assistant speaks Gemma's answer.

The proposed updated version imports:

```python
from tts_engine import speak
```

and after generating the answer:

```python
answer = str(answer).strip()
print()
print("Gemma:", answer)

if answer:
    try:
        speak(answer)
    except Exception as error:
        print(f"TTS error: {error}")
```

This integration is **proposed but not yet verified end-to-end**.
